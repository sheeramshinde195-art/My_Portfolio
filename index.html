Hospital Patient & Billing Analysis

Python | Pandas | NumPy | MySQL | SQL | EDA | Data Visualization

Business Problem

Hospital management needed clarity on patient visits, department performance, waiting time, satisfaction, and billing patterns.

My Approach

Cleaned patient and billing data using Pandas, stored it in MySQL, and analyzed it using SQL queries, CTEs, and window functions.

Key Analysis

Department-wise visits, billing trends, patient satisfaction, waiting-time patterns, and high-value billing segments.

Outcome

Created KPIs, visual insights, and recommendations that can support better operational and billing decisions.

Customer Churn Analysis

Python | Pandas | NumPy | MySQL | SQL | EDA | Data Visualization

Business Problem

Businesses needed to understand why customers were leaving, identify high-risk customer segments, and analyze the factors affecting customer retention.

My Approach

Cleaned and transformed customer data using Python, Pandas, and NumPy. Stored and analyzed data using MySQL and SQL queries, including CTEs and window functions, to identify churn patterns and customer behavior.

Key Analysis

Customer churn rate, contract type analysis, tenure-based churn, monthly charges, payment methods, service usage, and customer segments with high churn rates.

Outcome

Identified key churn patterns, developed KPIs and visual insights, and provided data-driven recommendations to improve customer retention and reduce churn.
